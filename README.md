 MOBA / AOS 장르의 팀 기반 전투 게임  
 리그 오브 레전드의 'Arena' 모드를 참고한 3D 팀 프로젝트로,  
 캐릭터 스킬 구현과 UI 연동을 개발했습니다.

---

## 🔹 프로젝트 개요

- **프로젝트명**: ArenaJjap  
- **장르**: MOBA / AOS (리그 오브 레전드 아레나 모작)  
- **플랫폼**: PC  
- **개발 기간**: 21일  
- **개발 형태**: Unity 3D 팀 프로젝트 (4인)

---

## 🔹 주요 기능 (담당 파트 기준)

###  트린다미어 캐릭터 구현 
- 기본 공격 및 스킬 4종 구현 (Q, W, E, R)  
- 궁극기 발동 시 무적 상태 부여 (`isImmortal`, `SetState`)  
- 쿨타임 및 상태 전환 제어 로직 구성  
- 캐릭터 상태와 애니메이션 간 연동 처리

###  UI 쿨타임 연동 
- 스킬 아이콘에 쿨타임 `fillAmount` 연동  
- 스킬 사용 시 애니메이션과 UI 업데이트 동기화  
- 캐릭터 스크립트와 UI 사이의 인터페이스 설계 경험

## 🔹 회고

이 프로젝트에 참여하기 전까지 상속 개념을 제대로 이해하지 못했지만,  
실제 캐릭터 기능과 UI를 연결하면서 상속 구조를 직접 설계하고 활용하는 경험을 쌓을 수 있었다.  
특히 공통 캐릭터 로직과 개별 클래스 간 구조 차이를 체감하며,  
상속의 필요성과 유지보수 관점의 중요성을 제대로 이해하게 된 프로젝트였다.
